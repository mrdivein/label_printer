ECG Label Tool v20 — Live Designer

Key changes
- Single live layout: Designer changes immediately update Preview and Print Current. Saving only persists the template.
- Persistent user data in %APPDATA%\ECG_Label_Tool: templates, printer profiles, workspace settings, unsaved recovery.
- Multi-select by drag rectangle or Shift+Click.
- Lock / unlock elements. Locked elements still print but cannot move/resize/delete.
- Drag/resize Virtual Print Area directly on canvas; guide only, never clips printing.
- Drag the orange fold boundary directly.
- Resize element boxes with handles; line endpoints have handles.
- Font size +/- buttons and multi-selection font adjustment.
- Add free text, data fields, lines, rectangles, filled rectangles and ellipses.
- Undo/Redo, duplicate, delete, align, keyboard nudging.
- Test Print directly from Designer.
- Automatic working-copy recovery after app/update/restart.
- Last template, printer, window geometry, Excel source/sheet, Google Sheet URL/tab, Instant Print, zoom and move step are remembered.
- Template saves keep the 5 latest backups in %APPDATA%\ECG_Label_Tool\template_backups.

Important
The Virtual Print Area remains only a visual guide. Physical calibration/offset is separate and the designer never hard-clips output to this guide.
